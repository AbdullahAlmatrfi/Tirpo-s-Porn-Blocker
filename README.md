A Porn Blocker Extension

A Chrome extension to block pornography, adult content, and NSFW websites. Protects users from 100,000+ adult sites.

## Features
- Blocks 100,000+ adult content websites
- Category-based blocking (Adult, Social Media, Gaming)
- Custom site blocking
- Cache system for better performance
- 30-second delay for unblocking" > README.md

- User can block sites by category or add them to the block list. If user attempts to go to site they will be redirected to a block page.
